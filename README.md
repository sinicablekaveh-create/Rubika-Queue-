# Remote Sender
Android queue helper for Bale, Eitaa and Rubika.

- Imports up to 1000 unique numbers from XLSX.
- Normalizes Iranian mobile numbers to +98.
- Queue spacing 1–1440 minutes.
- Creates a deterministic local contact for the current recipient.
- Opens the selected installed messenger and shares the message text.
- The user confirms the recipient and taps Send in the messenger.
- After returning, MARK SENT advances the queue and enforces the configured interval.
- Test recipient defaults to +989106119487.

Package IDs used: Bale ir.nasim, Eitaa ir.eitaa.messenger, Rubika ir.resaneh1.iptv.
